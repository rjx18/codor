## Design Context

### Users
People coordinating several AI coding agents from a desktop or phone. They need to see who said what, understand active roles, and direct work without learning an internal protocol.

### Brand Personality
Calm, capable, and candid. Codor should feel like a focused messaging workspace rather than an infrastructure console.

### Aesthetic Direction
Preserve Codor's restrained soft-editorial visual system. Make the transcript read like a familiar messaging app: the operator on the right and other participants on the left. Message bubbles and participant marks share one durable identity. Default that identity from the service when possible: Claude orange, Codex monochrome, Gemini blue, and the human operator green. Use the service's existing bundled mark for agent avatars. A manually selected color overrides the service default; duplicate active colors are unavailable within a channel.

### Design Principles
- Conversation first: every authored message has a clear bubble and side.
- Identity stays consistent: one durable color follows each participant across the channel.
- Color supports names and avatars; it never replaces them as the only identity cue.
- Complex agent output remains readable, even when a bubble contains tools, code, or attachments.
- Background collaboration context stays out of the visible transcript.
